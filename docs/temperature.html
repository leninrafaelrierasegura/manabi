1 Introduction

Data was downloaded from WorldClim using the geodata package. The data represents average monthly temperature at a spatial resolution of 30 arc-seconds (approximately 1 km² at the equator). You get 12 raster layers, one for each month of the year. The data is in degrees Celsius and it was collected from 1970 to 2000.

Go to this file to see how the data was handled.

Here is a summary of the steps taken:

  • For the monthly average temperature data, we calculated the mean across the 12 layers to get the average climatology.

  • For the monthly minimum temperature data, we calculated the minimum across the 12 layers.

  • For the monthly maximum temperature data, we calculated the maximum across the 12 layers.

  • We then clipped the rasters to the area of interest (Manabí province) using a polygon shapefile.

  • Finally, we applied a condition to identify suitable areas where the minimum temperature is greater than or equal to 18°C and the maximum temperature is less than or equal to 30°C. (this is done in this file)

manabi_avg_temp <- rast("clean_data/manabi_avg_temp.tif")
manabi_min_temp <- rast("clean_data/manabi_min_temp.tif")
manabi_max_temp <- rast("clean_data/manabi_max_temp.tif")

# Compute global range
all_min <- min(minmax(manabi_avg_temp), minmax(manabi_min_temp), minmax(manabi_max_temp))
all_max <- max(minmax(manabi_avg_temp), minmax(manabi_min_temp), minmax(manabi_max_temp))

2 Avearage Temperature

mapview(manabi_avg_temp, layer.name = "Avg Temp (°C)", at = seq(all_min, all_max, length.out = 101), legend = FALSE)

3 Minimum Temperature

mapview(manabi_min_temp, layer.name = "Min Temp (°C)", at = seq(all_min, all_max, length.out = 101), legend = FALSE)

4 Maximum Temperature

mapview(manabi_max_temp, layer.name = "Max Temp (°C)", at = seq(all_min, all_max, length.out = 101), legend = FALSE)

5 Suitable area

suitable_area <- (manabi_min_temp >= 19.5) & (manabi_max_temp <= 30)

suitable_min <- mask(manabi_min_temp, suitable_area, maskvalues = 0)
suitable_max <- mask(manabi_max_temp, suitable_area, maskvalues = 0)

# Stack the two rasters into a single multi-layer raster
suitable_stack <- c(suitable_min, suitable_max)

# Optional: rename the layers for clarity
names(suitable_stack) <- c("Tmin", "Tmax")

Below we show the minimum temperature layer of the suitable area. The important thing is the area.
